# Диапазоны Lite-анархий

HubSwap использует четыре диапазона для четырёх страниц меню Lite:

- `solo` — Соло, страница 1;
- `duo` — Дуо, страница 2;
- `trio` — Трио, страница 3;
- `clan` — Клан, страница 4.

Общий файл находится в корне репозитория: `anarchy_ranges.json`.

Пример:

```json
{
  "solo": { "start": 1, "end": 17 },
  "duo":  { "start": 18, "end": 38 },
  "trio": { "start": 39, "end": 57 },
  "clan": { "start": 58, "end": 74 }
}
```

## Как обновить диапазоны всем

1. Измени `anarchy_ranges.json` в ветке `main` репозитория `Heldyy90/HubSwap`.
2. Закоммить и отправь изменения на GitHub.
3. Клиенты HubSwap проверяют raw-версию этого файла примерно раз в 15 минут.
4. Если файл корректный, новые значения сохраняются в локальный `hubswap.json` и сразу используются для следующих переходов.

Перезапуск Minecraft не нужен.

## Локальная настройка

В меню HubSwap есть вкладка **«Диапазоны»**. В ней можно менять значения Соло / Дуо / Трио / Клан вручную.

Переключатель **«Общие диапазоны»** определяет приоритет:

- **ВКЛ** — общий файл с GitHub имеет приоритет и при очередной проверке заменит локальные значения;
- **ВЫКЛ** — удалённая синхронизация не выполняется, используются только локальные значения.

## Проверка значений

- номера должны быть больше `0`;
- начало диапазона не может быть больше конца;
- диапазоны не должны пересекаться;
- на одной странице допускается не более 36 серверов.

Если удалённый файл недоступен или содержит неверные значения, HubSwap продолжит использовать последние корректные локальные диапазоны.
