# HubSwap

**Автоматический переход между серверами (Lite / Classic / Prime / Lite 1.20) на проекте HolyWorld.**

Мод позволяет быстро переключаться между серверами через команды, хоткеи и кликабельные ссылки в чате. Поддерживаются настраиваемые алиасы, диапазоны серверов и статистика переходов.

---

## 🔧 Возможности

- **4 режима:** Lite (1–74), Classic (1–5), Prime (1–9), Lite 1.20 (1–3).
- **Команды:** основные (`/ln`, `/cn`, `/pm`, `/ln120`) и **настраиваемые алиасы** (например, `/an`, `/ан`, `/ft`).
- **Подкоманды:** `top` и `down` для навигации по серверам (например, `/an top 3`).
- **Хоткеи:** до 8 клавиш с привязкой к режиму и номеру сервера.
- **Ссылки в чате:** кликабельные названия серверов (например, «Лайт #12» или «Classic #2»).
- **Автосохранение статистики:** каждые 30 секунд и при завершении/отключении клиента.
- **Настройка диапазонов:** для Lite можно изменять категории Solo/Duo/Trio/Clan.
- **Цветовые темы и уведомления:** настраиваемый интерфейс.

---

## 📦 Установка

1. Скачайте последний релиз из [Releases](https://github.com/HolyWorldWEB/HubSwap/releases).
2. Поместите `.jar` файл в папку `mods` вашего клиента Fabric (версия 1.20.1 для текущей ветки разработки).
3. Запустите игру.

---

## ⌨️ Команды

### Основные
| Команда          | Действие                         |
|------------------|----------------------------------|
| `/ln <номер>`    | Переход на Lite #номер           |
| `/ln120 <номер>` | Переход на Lite 1.20 #номер      |
| `/cn <номер>`    | Переход на Classic #номер        |
| `/pm <номер>`    | Переход на Prime #номер          |

### Алиасы
Вы можете добавить свои алиасы через GUI (вкладка «Режимы»). Например:
- `an`, `ан`, `ft` → Lite (по умолчанию)
- `cl` → Classic
- `pr` → Prime

Для любого алиаса работают подкоманды:
- `/алиас top [шаг]` → переход на N серверов вверх;
- `/алиас down [шаг]` → переход на N серверов вниз.

*Пример:* `/an top 3` → переключиться на 3 сервера вверх в режиме Lite.

---

## 🎮 Хоткеи

В настройках (вкладка «Хоткеи») можно привязать до 8 клавиш к конкретному переходу:
- выберите клавишу;
- выберите режим (Lite / Classic / Prime / Lite 1.20);
- укажите номер сервера;
- включите хоткей.

При нажатии клавиши мод автоматически выполнит переход.

---

## 🔗 Ссылки в чате

Мод автоматически преобразует названия серверов в кликабельные ссылки.
Поддерживаются варианты:
- **Lite:** `Лайт #12`, `lite 12`, `Лайт12`;
- **Classic:** `Классик #3`, `Classic 3`, `Clasik#2`;
- **Prime:** `Прайм #7`, `Prime7`;
- **Lite 1.20:** `лайт 1.20 #2`, `lite120 1`.

Ссылки создаются только для номеров, которые входят в текущий допустимый диапазон режима.

## ⚙️ Настройки

Откройте GUI настроек клавишей `F6` (по умолчанию).

### Вкладки
- **Основные:** таймаут, уведомления, цветовая тема, цвет ссылок.
- **Режимы:** настройка алиасов для каждого режима.
- **Диапазоны:** настройка количества серверов и категорий Lite (Solo/Duo/Trio/Clan).
- **Хоткеи:** привязка клавиш.
- **Статистика:** общее число переходов, любимые серверы, время на серверах.

---

## 🛠️ Настройка диапазонов

Для режима **Lite** задаются непрерывные диапазоны категорий Solo, Duo, Trio и Clan. Диапазоны должны идти от 1 без пропусков; общее количество серверов вычисляется по последней границе.

1. Откройте настройки (`F6`).
2. Перейдите во вкладку **«Диапазоны»**.
3. Измените Min/Max нужных категорий.
4. Нажмите **«Сохранить»**.
5. Изменения применяются без перезапуска; проверка допустимого номера выполняется в момент команды.

---

## 📂 Файлы конфигурации

- `config/hubswap.json` – основные настройки (алиасы, диапазоны, хоткеи, темы).
- `config/hubswap_stats.json` – статистика переходов.

При загрузке поддерживаются устаревшие названия режимов `light` / `light120` и старые настраиваемые команды из `hubswap.json`.
