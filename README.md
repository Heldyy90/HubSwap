## 📌 Описание

**HubSwap** — это Fabric-мод для Minecraft, созданный для игроков и модераторов на **HolyWorld**.

Он ускоряет переход между серверами **Anarchy**, **Lite-Anarchy** и **Lite 1.20**, добавляет удобные команды, кликабельные названия серверов в чате, настройки задержек, уведомления и визуальные параметры.

Мод особенно удобен, когда нужно быстро перейти на нужную анархию без ручного поиска сервера в меню.

## ✨ Возможности

| Возможность | Описание |
|---|---|
| ⚡ Автопереход | Переход на нужный сервер через последовательность действий: хаб → выбор режима → выбор сервера |
| ⏱️ Настройка задержек | Можно настроить задержку после `/hub` и задержку между кликами |
| ⌨️ Быстрые команды | Поддержка команд `/cn`, `/ln`, `/ln120` |
| 🌍 RU/EN раскладка | Команды работают и на английской, и на русской раскладке клавиатуры |
| 🖱️ Кликабельный чат | Названия серверов в чате становятся кликабельными |
| 🎨 Визуальные настройки | Можно менять тему интерфейса и цвет кликабельных ссылок |
| 🔔 Уведомления | Мод показывает уведомления о переходе, их можно включить или выключить |
| 🛠️ Удобство для модераторов | Быстрый переход помогает быстрее проверять разные сервера |
