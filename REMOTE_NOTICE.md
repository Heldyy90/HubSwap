# Удалённые объявления HubSwap

Мод читает файл `announcement.json` из ветки `main` репозитория:

`https://raw.githubusercontent.com/Heldyy90/HubSwap/main/announcement.json`

Проверка выполняется при входе в Hub и затем каждые 10 секунд, пока игрок остаётся в Hub. Перезапуск Minecraft не нужен.

## Обычное объявление

```json
{
  "enabled": true,
  "type": "announcement",
  "id": "message",
  "revision": 1,
  "title": "Важная информация",
  "lines": [
    "Первая строка сообщения.",
    "Вторая строка сообщения."
  ],
  "version": "",
  "downloadUrl": "",
  "downloadButton": false
}
```

Любое изменение текста или других полей создаёт новый отпечаток сообщения, поэтому изменённый текст появится у игроков автоматически. `revision` можно увеличивать для удобства, но это не обязательно.

## Сообщение об обновлении

```json
{
  "enabled": true,
  "type": "update",
  "id": "update-1.0.8",
  "revision": 1,
  "title": "Доступно обновление HubSwap",
  "lines": [
    "Добавлена новая функция.",
    "Исправлены ошибки переходов."
  ],
  "version": "1.0.8",
  "downloadUrl": "https://github.com/Heldyy90/HubSwap/releases/latest",
  "downloadButton": true
}
```

Поведение обновления:

- если установленная версия уже равна или новее `version`, сообщение не показывается;
- кнопка `СКАЧАТЬ` открывает ссылку и скрывает это уведомление до перезапуска Minecraft;
- если после перезапуска старая версия всё ещё установлена, уведомление появится снова;
- после установки новой версии уведомление больше не появится;
- `СКРЫТЬ УВЕДОМЛЕНИЕ` сохраняет скрытие именно текущего текста;
- если содержимое `announcement.json` изменить, новое сообщение снова сможет появиться.

Чтобы временно отключить удалённое сообщение, поставьте:

```json
"enabled": false
```
